🎯 Objetivo

Seu objetivo é criar um arquivo completo chamado friedland-brandbook.html, que funcione como um brandbook digital oficial altamente profissional, visualmente sofisticado e tecnicamente estruturado, servindo como fonte única de verdade (single source of truth) para qualquer material futuro da marca Friedland Law (site, apresentações, documentos, peças gráficas, etc.).

📥 Inputs (serão fornecidos separadamente)

Você deve analisar e integrar cuidadosamente os seguintes materiais:

Design System atualizado do site
Arquivo index.html do site original
Repositório GitHub do site atual (em construção)
Arquivos .png das logos oficiais da Friedland Law
🧠 Instruções (seguir passo a passo)
1. Análise Inicial
Analise profundamente todos os inputs
Identifique padrões visuais, tipográficos, cores, espaçamentos, grids e componentes
Detecte inconsistências e padronize com base na versão mais atual/confiável
2. Estrutura do Brandbook (HTML)

Construa o arquivo HTML com as seguintes seções bem organizadas:

2.1 Introdução
Sobre a marca Friedland Law
Posicionamento e proposta de valor
Tom de voz e personalidade da marca
2.2 Logotipo
Versões oficiais (horizontal, vertical, ícone, etc.)
Uso correto
Uso incorreto (com exemplos visuais)
Espaçamento mínimo (clear space)
Tamanhos mínimos
2.3 Paleta de Cores
Cores primárias, secundárias e neutras
Códigos HEX, RGB e HSL
Exemplos de uso
Hierarquia e proporções
2.4 Tipografia
Fontes principais e secundárias
Hierarquia tipográfica (H1, H2, H3, body, etc.)
Exemplos práticos de uso
Regras de espaçamento e legibilidade
2.5 Componentes de UI
Botões (estados: hover, active, disabled)
Inputs
Cards
Navegação
Outros elementos relevantes do design system
2.6 Layout e Grid
Estrutura de grid
Margens e espaçamentos
Responsividade
2.7 Diretrizes de Imagens
Estilo fotográfico
Uso de ícones
Ilustrações (se houver)
2.8 Aplicações
Exemplos reais (mockups ou simulações)
Como aplicar a identidade em diferentes contextos
3. Requisitos Técnicos do HTML
Código limpo, semântico e bem estruturado
Uso de HTML5 + CSS interno (ou organizado dentro do arquivo)
Design moderno e responsivo
Visual premium (nível grandes escritórios internacionais)
Organização clara para futura manutenção
Comentários explicativos no código
4. Qualidade Visual
O design deve transmitir:
Sofisticação
Autoridade jurídica
Confiança
Clareza
Evitar aparência genérica ou “template básico”
Priorizar estética editorial + institucional
5. Output Esperado
Um único arquivo completo: friedland-brandbook.html
Pronto para uso imediato
Visualmente impressionante
Estruturado para servir como referência oficial da marca
6. Regras Extras
Sempre priorize consistência visual
Justifique decisões quando necessário (em comentários no código)
